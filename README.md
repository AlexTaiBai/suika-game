# 🍉 合成大西瓜 (Suika Game)

一个简单有趣的水果合成游戏，灵感来源于经典的合成大西瓜 / Suika Game。

## 玩法

- 点击画布选择落点，放下水果
- 相同的水果碰撞会合成更大的水果
- 合成顺序：葡萄 → 樱桃 → 橘子 → 柠檬 → 猕猴桃 → 番茄 → 桃子 → 菠萝 → 椰子 → 半个西瓜 → 大西瓜
- 水果堆叠超过红线则游戏结束
- 努力合成大西瓜并获得高分！

## 运行

直接在浏览器中打开 `index.html` 即可开始游戏。

## 技术

纯 HTML + Canvas + 原生 JavaScript 实现，包含简单的物理模拟（重力、碰撞、反弹）。
